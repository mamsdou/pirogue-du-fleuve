# Pirogue du Fleuve

Jeu d'arcade dans le navigateur : guide une pirogue sur le fleuve au crépuscule, attrape les poissons, évite les rochers et les crocodiles. Le courant accélère avec le temps.

## Jouer

Ouvre `index.html` dans un navigateur. Aucune installation n'est nécessaire.

## Règles

- Poisson : +10 points
- Calebasse dorée : bouclier pendant 5 secondes
- Rocher ou crocodile : -1 vie (3 vies au départ)
- Le record est enregistré dans le navigateur (localStorage)

## Commandes

- Clavier : flèches ← →, ou A / D, ou Q (AZERTY)
- Mobile : glisse le doigt sur l'écran
- Espace ou Entrée pour lancer une partie

## Installer sur téléphone

Le jeu est une application web installable (PWA) : une fois installé, il s'ouvre en plein écran avec son icône et marche sans internet.

- **iPhone (Safari)** : ouvre le lien du jeu, touche le bouton Partager, puis « Sur l'écran d'accueil ».
- **Android (Chrome)** : ouvre le lien du jeu, touche le menu ⋮, puis « Installer l'application » (ou « Ajouter à l'écran d'accueil »).

Le jeu doit être servi en HTTPS (par exemple avec GitHub Pages) pour pouvoir être installé.
